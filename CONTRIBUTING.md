# Contributing to AKN-PT

This project is in **pre-foundation** state. Foundational decisions are still being made (see [docs/adr/](docs/adr/)). Contributions are welcome, but please read the relevant ADRs first to understand the constraints.

## How to contribute

1. **Open an issue first** for non-trivial changes. We want to align on direction before code is written.
2. **Sign your commits** (`git commit -s`) to certify the Developer Certificate of Origin.
3. **Follow the file/folder layout** described in the [README](README.md).
4. **Write in PT-PT** for content that targets Portuguese audiences (specification body, examples, validator messages). Write in **English** for ADRs, outreach material, and code comments.

## What's welcome

- Review of ADRs (questions, alternatives, objections)
- Real-world legislative drafting expertise — especially edge cases in Portuguese act typology
- Akoma Ntoso community knowledge — what other national profiles got right or wrong
- Testing against real diplomas
- Improvements to validator messages

## What's not yet ready

- Schema changes (the XSD is not yet drafted)
- Validator implementation (it has no stable schema to validate against)

These will open up after Milestone M2.
